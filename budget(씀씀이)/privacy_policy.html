개인정보처리방침

시행일: 2026년 5월 20일

1. 수집하는 개인정보 항목

필수 로그인 정보 (Google / Facebook)

  • 이름, 이메일 주소, 프로필 사진

필수 가계부 데이터

  • 사용자가 직접 입력하거나 알림을 통해 자동 등록된 수입·지출 내역
  • 금액, 카테고리, 날짜, 메모

선택 알림 접근

  • 알림 자동 등록 기능 사용 시, 기기에 수신된 알림 제목 및 내용
  • 결제 금액 추출 목적으로만 사용되며, 서버에 전송되지 않습니다
  • 금액·카테고리 추출 후 즉시 파기됩니다

선택 광고 식별자

  • Google AdMob SDK를 통한 광고 식별자 (GAID)

2. 개인정보 수집 목적

항목 이용 목적
로그인 정보 계정 인증 및 사용자 식별
가계부 데이터 수입·지출 내역 저장 및 통계 제공
알림 내용 카드·은행 알림에서 결제 금액 자동 추출
광고 식별자 맞춤형 광고 제공 (Google AdMob)

3. 개인정보 보유 및 이용 기간

  • 가계부 데이터: 회원 탈퇴 또는 삭제 요청 시 즉시 파기
  • 로그인 정보: Google / Facebook 계정 연동 해제 시 삭제
  • 알림 내용: 금액 추출 후 앱 내에서 즉시 파기, 저장하지 않음

4. 제3자 제공 및 위탁

본 앱은 아래 서비스를 이용하며, 각 서비스의 개인정보처리방침을 따릅니다.

서비스 목적 운영사
Firebase Authentication 소셜 로그인 인증 Google LLC
Firebase Realtime Database 가계부 데이터 저장 Google LLC
Google AdMob 배너·전면 광고 제공 Google LLC
Facebook Login SDK 페이스북 로그인 인증 Meta Platforms, Inc.
개인정보는 위 서비스 제공 목적 이외에 제3자에게 제공하지 않습니다.

5. 이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 데이터 삭제: 앱 내 설정 → 로그아웃 후 계정 데이터 삭제 요청
  • 알림 접근 권한 철회: 기기 설정 → 앱 → 알림 접근 권한 해제
  • 광고 맞춤화 거부: 기기 설정 → Google → 광고 → 광고 개인최적화 해제

6. 아동 개인정보 보호

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 개인정보 보안

수집된 개인정보는 Firebase의 보안 규칙을 통해 인증된 사용자 본인만 접근할 수 있도록 보호됩니다. 타인의 데이터에는 접근할 수 없습니다.

8. 개인정보처리방침 변경

방침이 변경될 경우 앱 내 공지 또는 업데이트를 통해 사전 안내합니다.
